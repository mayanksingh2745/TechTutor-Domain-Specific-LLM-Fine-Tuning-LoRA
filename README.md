# TechTutor: Domain-Specific LLM Fine-Tuning with LoRA

Welcome to **TechTutor**, a project focused on fine-tuning the Mistral-7B Large Language Model to specialize in Electronics and Communication Engineering (ECE) and Machine Learning (ML) domains. This project leverages Parameter-Efficient Fine-Tuning (PEFT) techniques, specifically LoRA and QLoRA, to efficiently train the model.

## Objective

The main goals of this project are:
- **Synthetic Dataset Curation**: Create and curate a 5,000-sample synthetic dataset tailored for ECE/ML domain-specific tasks.
- **Model Fine-Tuning**: Fine-tune the Mistral-7B model using QLoRA for memory-efficient training while maintaining high accuracy.
- **Performance Tracking**: Track performance metrics and optimize hyperparameter selection using Weights & Biases (W&B).

## Tech Stack
- **Base Model**: Mistral-7B
- **Fine-Tuning**: PEFT (LoRA, QLoRA)
- **Frameworks**: Hugging Face Transformers, PyTorch, Accelerate
- **Monitoring**: Weights & Biases (W&B)
